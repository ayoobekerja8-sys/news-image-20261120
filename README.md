A one-image newspaper front page summing up Friday 20 November 2026 — 52 stories, 12 features, a world map, a date-check strip and the day in numbers. Built for the make.fun bounty https://make.fun/bounty/news-image-20261120

## How to run

`python3 draw.py` regenerates `entry.png` (deterministic). `python3 main.py` copies `entry.png` to the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).
